Paste-ready text for the Logitech Marketplace submission form. Kept in the repository so the
listing and the plugin cannot drift apart — if the behaviour changes, this changes with it.


97 characters.

## Detail page description

```
Three keys on your MX Creative Keypad, for your GitHub Copilot CLI sessions:

• Active — how many are working right now
• Waiting — how many are waiting on you
• Sessions — how many are open at all

Each opens a folder listing those sessions, with the project, the branch and how long it has been
in that state. Press a tile to jump straight to that terminal pane.

Waiting stays honest: it counts only a session blocked on a permission prompt, or one holding for
your next prompt. A number there always means something needs doing.

Works with Warp and iTerm2, on macOS.
Connects in two presses — it writes one hooks file, and removes it the same way.
Nothing leaves your machine: no network, no telemetry.
```

130 words. Kept short on purpose: a detail page is skimmed, and the three counts are the whole
product. Everything that used to sit here — the requirements list, the privacy detail — is a click
away on the linked home page, where it is also kept current.
